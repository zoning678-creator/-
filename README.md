# 团建活动管理 App（Python + HTML）

这是一个示例应用，包含 3 个模块：

- 商家入驻管理
- 用户社群管理（创建社群、加入社群、发布帖子）
- 管理者后台数据分析

## 技术栈

- 后端：Python（标准库 HTTP Server，无第三方依赖）
- 前端：HTML + CSS + 原生 JavaScript

---

## 一步一步操作（新手版）

> 如果你不熟悉开发环境，按下面顺序照着做即可。

### 第 1 步：确认你在项目目录

打开终端后执行：

```bash
pwd
```

你应该看到路径是：

```text
/workspace/-
```

如果不是，请执行：

```bash
cd /workspace/-
```

---

### 第 2 步：确认 Python 可用

执行：

```bash
python3 --version
```

如果能看到版本号（例如 `Python 3.10.x` 或更高），说明可继续。

---

### 第 3 步：启动应用

执行：

```bash
python3 app.py
```

看到类似下面输出，表示服务已启动：

```text
Server running at http://0.0.0.0:8000
```

> 注意：这个终端窗口要保持运行，不要关闭。

---

### 第 4 步：打开浏览器看首页

在浏览器地址栏输入：

```text
http://127.0.0.1:8000/
```

你会看到“团建活动平台”页面，包含：

- 商家入驻表单
- 社群创建/加入/发帖区域

---

### 第 5 步：先做一条“商家入驻”

在“商家入驻”中填写：

- 商家名称：星火拓展
- 商家类别：户外拓展
- 联系人：张经理
- 城市：上海

点击“提交入驻”。

预期效果：下方商家列表出现一条记录。

---

### 第 6 步：创建一个社群

在“用户社群管理”中填写：

- 社群名称：周末团建营
- 创建者用户名：alice
- 社群简介：每周组织一次轻团建

点击“创建社群”。

预期效果：社群列表出现新社群（会有社群 ID，例如 `#1`）。

---

### 第 7 步：加入社群

在“加入社群”区域填写：

- 社群ID：1
- 用户名：bob

点击“加入社群”。

预期效果：该社群成员数增加。

---

### 第 8 步：发布帖子

在“发布帖子”区域填写：

- 社群ID：1
- 发帖用户：bob
- 帖子内容：下周去飞盘团建吧！

点击“发布帖子”。

预期效果：该社群帖子数增加。

---

### 第 9 步：查看管理后台分析

打开：

```text
http://127.0.0.1:8000/admin
```

你会看到：

- KPI（商家总数、社群总数、帖子总数、社群平均人数）
- 商家类别分布
- 热门社群排行

---

### 第 10 步：结束运行

回到第 3 步那个终端，按：

```text
Ctrl + C
```

服务会停止。

---

## 常见问题（按现象排查）

### 1) 打不开 `127.0.0.1:8000`

- 检查是否执行了 `python3 app.py`
- 检查启动终端有没有报错
- 检查端口是否被占用

可用以下命令查看 8000 端口占用（Linux/macOS）：

```bash
lsof -i :8000
```

---

### 2) 提示 `python3: command not found`

你的系统里可能没装 Python 3，需要先安装 Python 3 再运行。

---

### 3) 刷新后数据没了

这是当前版本的正常行为：数据保存在内存里，服务重启后会清空。

---

## 接口清单（可用于联调）

- `POST /api/merchants`：商家入驻
- `GET /api/merchants`：商家列表
- `POST /api/communities`：创建社群
- `GET /api/communities`：社群列表
- `POST /api/communities/<id>/join`：加入社群
- `POST /api/posts`：发布帖子
- `GET /api/posts`：帖子列表
- `GET /api/admin/analytics`：管理后台分析数据
