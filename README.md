# 团建活动管理 App（Python + HTML）

这是一个示例应用，包含 3 个模块：

- 商家入驻管理
- 用户社群管理（创建社群、加入社群、发布帖子）
- 管理者后台数据分析

## 技术栈

- 后端：Python（标准库 HTTP Server，无第三方依赖）
- 前端：HTML + CSS + 原生 JavaScript

---

## Windows 电脑：从“点击”开始（超详细）

> 你是 Windows 用户的话，优先看这一段。不会命令行也没关系，按步骤点就行。

### A. 先打开项目文件夹

1. 打开 **文件资源管理器**（任务栏黄色文件夹图标）。
2. 在地址栏输入：`/workspace/-`，按回车。
3. 你会看到项目文件，比如 `app.py`、`README.md`、`templates`、`static`。

### B. 打开终端（推荐 PowerShell）

1. 在当前文件夹空白处点击鼠标右键。
2. 点击 **“在终端中打开”**（有些系统显示“Open in Terminal”）。
3. 会弹出 PowerShell 窗口。

### C. 检查 Python 是否安装

在 PowerShell 里复制粘贴并回车：

```powershell
python --version
```

- 如果显示 `Python 3.x.x`：继续下一步。
- 如果提示找不到命令：先安装 Python（安装时勾选 **Add Python to PATH**），装完重开终端。

### D. 启动项目

在 PowerShell 里执行：

```powershell
python app.py
```

看到类似输出：

```text
Server running at http://0.0.0.0:8000
```

表示启动成功。

> 这一窗口不要关，关了服务就停了。

### E. 打开网页并开始“点击操作”

1. 打开浏览器（Edge/Chrome 都可以）。
2. 地址栏输入：`http://127.0.0.1:8000/` 回车。
3. 页面里你会看到两个区域：
   - 商家入驻
   - 用户社群管理

### F. 首页怎么点（逐项点击）

#### 1）商家入驻

- 点击“商家名称”输入框，输入：`星火拓展`
- 点击“商家类别”输入框，输入：`户外拓展`
- 点击“联系人”输入框，输入：`张经理`
- 点击“城市”输入框，输入：`上海`
- 点击按钮：**提交入驻**

预期：下方出现一条商家记录。

#### 2）创建社群

- 点击“社群名称”，输入：`周末团建营`
- 点击“创建者用户名”，输入：`alice`
- 点击“社群简介”，输入：`每周组织一次轻团建`
- 点击按钮：**创建社群**

预期：下方出现社群，前面会有 `#1` 这种 ID。

#### 3）加入社群

- 在“社群ID”输入：`1`
- 在“用户名”输入：`bob`
- 点击按钮：**加入社群**

预期：社群成员数变大。

#### 4）发布帖子

- 在“社群ID”输入：`1`
- 在“发帖用户”输入：`bob`
- 在“帖子内容”输入：`下周去飞盘团建吧！`
- 点击按钮：**发布帖子**

预期：社群帖子数变大。

### G. 去管理后台看结果

1. 点击首页顶部按钮 **“进入管理后台”**，或者地址栏输入：`http://127.0.0.1:8000/admin`
2. 你会看到：
   - 商家总数
   - 社群总数
   - 帖子总数
   - 社群平均人数
   - 商家类别分布
   - 热门社群

### H. 关闭项目

1. 切回 PowerShell 窗口。
2. 键盘按 `Ctrl + C`。
3. 出现命令输入提示符，表示服务已停止。

## 常见问题（按现象排查）

### 1) 打不开 `127.0.0.1:8000`

- 检查是否执行了 `python3 app.py`
- 检查启动终端有没有报错
- 检查端口是否被占用

可用以下命令查看 8000 端口占用（Linux/macOS）：

```bash
lsof -i :8000
```

---

### 2) 提示 `python3: command not found`

你的系统里可能没装 Python 3，需要先安装 Python 3 再运行。

---

### 3) 刷新后数据没了

这是当前版本的正常行为：数据保存在内存里，服务重启后会清空。

## 接口清单（可用于联调）

- `POST /api/merchants`：商家入驻
- `GET /api/merchants`：商家列表
- `POST /api/communities`：创建社群
- `GET /api/communities`：社群列表
- `POST /api/communities/<id>/join`：加入社群
- `POST /api/posts`：发布帖子
- `GET /api/posts`：帖子列表
- `GET /api/admin/analytics`：管理后台分析数据
